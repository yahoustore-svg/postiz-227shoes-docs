Informations sur les données

Ces informations décrivent l’installation locale de Postiz 227 Shoes et sa documentation publique.

Données de l’espace Postiz

Lorsqu’un compte est autorisé, Postiz peut recevoir son identifiant, son nom, sa photo de profil, les jetons d’autorisation et, selon les permissions accordées, des informations sur ses vidéos et des statistiques. Les textes, médias et paramètres des publications préparées dans l’espace sont également enregistrés.

Les données de l’installation Postiz sont conservées dans ses volumes Docker sur l’ordinateur de l’équipe. Les jetons sont utilisés pour les échanges avec les API officielles des réseaux sociaux. Ils ne sont pas publiés sur ce site ni dans son dépôt de documentation.

Médias destinés aux publications

Les médias ajoutés à Postiz sont également envoyés dans la médiathèque WordPress de 227shoes.com, hébergée chez o2switch. Leurs adresses HTTPS sont accessibles publiquement afin que les réseaux sociaux puissent les récupérer. Seuls des médias destinés à être diffusés doivent être ajoutés. La copie locale est conservée. Supprimer une copie locale ne supprime pas automatiquement la copie publique ; sa suppression doit aussi être demandée à l’équipe, qui vérifie les publications qui l’utilisent.

Services externes

Les réseaux sociaux traitent les autorisations et les requêtes adressées à leurs services selon leurs propres politiques. Cette page ne remplace pas les informations de confidentialité de TikTok, Meta ou Google.

Documentation publique

Le site est hébergé sur GitHub Pages. Il ne contient ni formulaire ni outil d’analyse ajouté par l’équipe. GitHub peut enregistrer les adresses IP des visiteurs pour la sécurité du service : informations sur GitHub Pages.

Retrait d’une autorisation et demandes

Une autorisation peut être révoquée dans les paramètres du réseau concerné. Pour demander la suppression des données locales ou poser une question, contacter 227shoes.contact@gmail.com. Une révocation côté réseau ne supprime pas automatiquement tous les contenus déjà enregistrés dans Postiz. Aucune durée de conservation automatique supplémentaire n’est configurée pour cet espace de test.
